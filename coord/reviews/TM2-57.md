## Verification
1. Root cause CONFIRMED. trade-mcp/src/index.ts:37 logs "trade-mcp started ..." and only at :43-44 registers SIGINT/SIGTERM. Between them there is no await, but the log write and the registration are separate steps, so a parent that signals on seeing the line can land in the window. Node's default SIGTERM action then kills the process: exit code null, and the "exit" hook (releaseLock, :35) never runs.
2. Scope OK: only trade-mcp/test/tm2_46_datadir_lock.edge.test.ts and coord/reports/TM2-57.md; no src change.
3. Preload (test:787-789, :791, :808): observes only (newListener -> queueMicrotask -> stderr marker); it never calls the listener or alters signals. It is opt-in via { sigtermReady } and used only for server c (:952). The microtask runs after main()'s synchronous tail (past :44), so the handler is installed. started requires the marker AFTER the started line (lastIndexOf > indexOf), so an earlier unrelated SIGTERM listener cannot satisfy it. Both lines go to stderr, so ordering is preserved.
4. whileFresh (:822-830) is sound: pins before fn, re-pins every 100 ms, clears in finally, tolerates lock removal. A real child reads mtime = now minus about 1 s +/- 100 ms whenever it looks. It hides nothing relevant: the intent is "a FRESH foreign lock is refused", which is exactly what it guarantees. The refusal message, exit code, port state and lock contents are still asserted. It does not test that a real lock stays fresh over real time, which is covered by the in-process edge checks.
5. cliProc (:832) uses async spawn, so the pin timer keeps running (spawnSync would block it). It is pushed on procs for cleanup. Exit 4 and the stderr message are asserted; oauth.json is checked unchanged.
6. Post-SIGKILL dead check (:915-916): exit event asserted {null, SIGKILL}, then kill(pid,0) must throw. Correct; the pid cannot be reused within microseconds in practice.
7. Stale path: age(OLD_HEARTBEAT), checkLock asserted stale, then nothing touches mtime (a is dead, pin cleared). Monotonic, so it cannot flip fresh.
8. Timeout 240 s is per-test via the options arg; the file-wide 90 s is unchanged. Reasonable for 4 tsx starts under load.
9. Intent preserved: refusals (exit 1 + message + no "started" + port closed), CLI exit 4, stale replacement message and lock owner, SIGTERM exit 0 with lock removed and no leftovers, noSecrets on all output. skipIf(IS_WIN) unchanged.

## Findings
- MEDIUM  trade-mcp/src/index.ts:37-44 (production, not part of this PR). The "started" log precedes the signal handlers, so a SIGTERM/SIGINT arriving right after startup (orchestrator restart, fast docker stop/start, supervisor probes) kills the process by signal without http.close or stopHeartbeat. Impact is minor but real: the lock is released only via the process "exit" hook, which does not run on signal death (the test shows the lock left behind), so the next start must wait out the 15 s live window or hit "already running" on a foreign host. Recommended follow-up (small src task): move process.on("SIGINT"/"SIGTERM", stop) above the started log (define stop right after http is created, before listen resolves). This would remove the need for the preload, and fix the same race in "second instance refuses ..." (SIGINT to server d at test:892-897) with no further test change. Until then, this PR's preload is a correct test-side workaround.
- LOW  test:885-897. The latent race in "second instance refuses ..." (SIGINT to d right after portOpen, and the earlier SIGTERM to c) is left unfixed. Acknowledged by the developer and out of this task's scope, but it can flake the same way; track it, or let the src fix cover it.
- LOW  test:787-789. The preload couples to index.ts's structure (marker after the sync tail of main()) and to stderr output. If the src fix lands, this should be deleted as redundant to avoid a dead helper.
- LOW  test:916. kill(pid,0) after exit relies on pid not being recycled; negligible, and a failure would be a false flake, not a false pass.
- INFO  test:907. The 240 s per-test timeout is a ceiling, not an expected runtime (4-17 s reported).
