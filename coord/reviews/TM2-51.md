# TM2-51 review: walk-forward equity guard (PR #84)

Verdict: APPROVE (no blocker, no high). Two small items worth a follow-up in tests/message.

Scope: only the guard in bt-service/bt_service/walkforward.py (L200-203), the new test file and coord/reports/TM2-51.md changed. In scope.
Wording `fold <i>: unexpected equity shape (<type>)` matches the brief. Scores, selection, ok and folds are untouched: the guard sits after the fold dict is appended and only affects the OOS curve.
Brief cases (None, dict, str, int, non-dict list items, empty list): none raises, each warns with the right type name, empty list does not warn.

## Findings

- MEDIUM walkforward.py:204-211 (with 200-203): on any fold after the first (prev_last is not None), a malformed equity is replaced by `[]`, so `first` is None and the pre-existing branch also appends `fold <i>: equity not rescaled (first value None)`. That is a second, misleading warning for the same fault (the equity was skipped, not mis-scaled). Fold 0 is clean, which is why the tests miss it. Suggest guarding the rescale warning (e.g. only when `equity` is non-empty), or accept and document. Not wrong output, so not high.
- LOW walkforward.py:186 vs 201: a malformed list shorter than MIN_FOLD_BARS (e.g. `[1,2,3]`) gets the shape warning and also `_bars`-based `thin test window (3 bars < 10)`: double warning. Longer malformed lists get only the shape warning. For None/dict/str/int, `_bars` returns None so there is exactly one warning. Behaviour is consistent with TM2-39 (`_bars` counts any list), just slightly noisy. Acceptable.
- LOW walkforward.py:202: a missing `equity` key now warns `(NoneType)`. Desirable: it is an unexpected shape and the brief's None case implies it. The old `or []` silently accepted None and falsy values (0, "", {}); these now warn too, which is correct.
- LOW walkforward.py:202: for a list with bad items the type shown is `list`, which is not informative. Optional improvement: `list of <first bad item type>`, but the brief fixes the wording `(<type>)`, so leave as is.
- INFO: a single non-dict item among valid dicts discards the whole curve for that fold (all-or-nothing). Matches the brief ("list of point dicts") and keeps the OOS curve consistent.
- INFO: the report claims the suite is green (2297 passed); I did not re-run it.
