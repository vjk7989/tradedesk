Decisions:
- **API** (https://docs.openalgo.in/api-documentation/v1/utilities-api/holidays.md):
  - request: `POST {OPENALGO_URL}/api/v1/market/holidays` with body `{"apikey", "year"?}`. `year` is omitted unless `--year` is given, so OpenAlgo uses the current year.
  - response: `{status, year, timezone, data[]}`, where each entry has `date`, `description`, `holiday_type`, `closed_exchanges` (list) and `open_exchanges` (list of `{exchange, start_time, end_time}`).
- **Mapping:**
  - Only `closed_exchanges` counts. NSE, BSE, NFO, BFO or CDS closed → `NSE`. MCX closed → `MCX`.
  - An exchange listed in `open_exchanges` (a special or partial session, e.g. Muhurat or MCX evening) is not a full closure and is not added, even if it is also listed as closed.
  - Other exchanges (BCD, NCO, CRYPTO) are ignored. Documented in `docs/holidays.md`.
- **Byte-preserving edit:**
  - `json.loads` validates the file.
  - A `JSONDecoder.raw_decode` scanner finds the exact span of the top-level `marketHolidays` value. It respects strings and brackets, so a decoy string elsewhere doesn't match.
  - Only that span is replaced, with compact one-line JSON. If the key is absent, it's appended as the last key with the detected indent and line ending (LF/CRLF).
  - The file is read and written as bytes. Tests assert every other byte is unchanged, including CRLF and 4-space-indent files.
- **Merge:** union, sorted, de-duplicated. Idempotent: an unchanged result isn't rewritten and no `.bak` is made.
- **Strict input:** an existing `marketHolidays` with keys other than NSE/MCX, non-list values or invalid dates → non-zero exit and the file is untouched, because trade-mcp's schema is `.strict()`.
- **Dates:** every date is validated with the trade-mcp `isoDate` rule (`YYYY-MM-DD` that round-trips).
- **Write:** atomic (temp file in the same dir, fsync, keep mode, `os.replace`) with `risk.json.bak`.
- **Exit codes:** non-zero on an HTTP error, network error, non-JSON reply, `status != success`, malformed dates or an invalid risk.json; the file is unchanged in all of them.
- **Secrets:** the key travels only in the POST body and is redacted from all messages (raw and stripped forms). No tracebacks are printed. Responses over 8 MiB are refused, and the HTTP timeout is a fixed 15 s constant (no flag).
- **`--dry-run`:** prints only the dates to be added per group and writes nothing.
- **Tests:** a local `ThreadingHTTPServer` fake, with no real network. They cover mapping, merge, idempotency, byte preservation, strict-schema output, failure cases, the key never in stdout or stderr, the key in the request body, dry-run, `.bak`, and a path with spaces.
- **Developers:** 1 sonnet. Fix rounds: 1 internal, before the PR (removed the unrequested `--timeout` flag; reject non-NSE/MCX keys; redact the stripped key).
