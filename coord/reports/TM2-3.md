Decisions:
- **API shape** (official docs; no remote MCP in `generateContent`, so the MCP client runs in-process):
  - an `@modelcontextprotocol/sdk` `Client` + `StreamableHTTPClientTransport(new URL(mcp.url), { requestInit: { headers: { Authorization: "Bearer …" } } })`;
  - wrapped with `mcpToTool(client)` from `@google/genai`;
  - passed in `ai.models.generateContent({ model, contents: prompt, config: { tools: [tool], abortSignal } })`, where automatic function calling runs the tool loop.
  - Sources: https://github.com/googleapis/js-genai (README, MCP section), https://ai.google.dev/gemini-api/docs/function-calling, https://ai.google.dev/gemini-api/docs/models.
  - The newer Interactions API `mcp_server` tool (server-side) was not used: it isn't part of `generateContent` and would need the MCP URL to be reachable by Google.
- **Dependencies**, pinned exact:
  - `@google/genai` 3.3.0, published 2026-11-12, the newest release at least 2 weeks old;
  - `@modelcontextprotocol/sdk` 1.32.2, the same as trade-mcp.
  - The lockfile grows by about 1.6k lines (genai's transitive deps).
- **Default model:** `DEFAULT_GEMINI_MODEL = "gemini-4-hydrogen"`, which the models page recommends for new projects. It carries no "stable" badge; `gemini-3.8-flash` is the stable alternative if you prefer it. Override order: `model` option, then `GEMINI_MODEL` (trimmed, empty = default). The key comes from `GEMINI_API_KEY`.
- **Mirrors `openai.ts`:**
  - https-only `validMcpSpec`;
  - an empty or whitespace MCP token or `GEMINI_API_KEY` is refused;
  - the token and key are redacted in text and errors;
  - `raceAbort` timeout → "timeout";
  - a prompt block → "refused";
  - a finish reason other than STOP → "response <reason>";
  - the MCP client is closed in `finally`.
- **Tool errors:** both kinds give ok:false with "tool error: <redacted, ≤300 chars>".
  - Thrown: a `callTool` that throws.
  - In-band: an MCP result with `isError`. The SDK maps that to `functionResponse.response.error` (`@google/genai` dist `McpCallableTool.callTool`), and the wrapper checks for it after the response.
