# TM2-59 - explicit-unit asserts in pass-through tests

Status: ready. Test-only; no source changes, no skips or filters. Values and intent are unchanged; no tests were added or removed.

Rule applied: resampled outputs (local_loader `_resample_to_interval` non-empty resample, pinned with `as_unit("ns")`) assert `"ns"`. Documented pass-through or refuse returns (empty, unsupported interval, same granularity, refused upsample, and paths that never normalise) assert `out.index.unit == <input>.index.unit`, with a comment. On pandas 3.1.1 those inputs are `us`, because they come from `date_range` or string parses.

## Per test
- test_tm15_warnings_edge.py `_expected()`: builds bin starts with `.as_unit("ns")`, so the expectation is in the asserted unit rather than inheriting one from `step`.
- test_tm15_warnings_edge.py::test_resample_irregular_gaps (1m interval): `out.index.unit == df.index.unit` (us), because a 1m request on 1m source is a same-granularity pass-through (`out is df`).
- test_tm15_warnings_edge.py::test_resample_irregular_gaps (other intervals): `out` and `exp` are `"ns"`, because the resample path pins ns.
- test_tm15_warnings_edge.py::test_resample_single_row: `out` and `exp` are `"ns"`, because a single row has no source granularity, so it is always resampled and pinned to ns.
- test_p93_anchor.py::test_3m_nse_same_as_first_bar_anchor: new and legacy are both `"ns"`. Both sides resample 1m to 3m, so each side is asserted on its own and the comparison cannot pass only because both sides share a unit.
- test_p93_anchor_edge.py::test_non_anchored_intervals_identical_to_legacy: new and legacy are both `"ns"`. Both resample a 1m source to 5m..1D.
- test_p93_anchor_edge.py::test_empty_frame_with_anchor: `out.index.unit == empty.index.unit`, because an empty frame is returned unchanged.
- test_p93_anchor_edge.py::test_same_granularity_with_anchor_unchanged: `out.index.unit == df.index.unit` (us), because same granularity is a documented pass-through.
- test_p93_anchor_edge.py::test_upsample_refused_with_anchor: `out.index.unit == df.index.unit` (us), because the upsample is refused and the source is returned unchanged.
- test_intervals_edge.py::test_local_resample_ohlcv_aggregation: `"ns"`, because 1m is resampled to 3m/10m.
- test_intervals_edge.py::test_local_resample_bins_aligned_to_session_open: `"ns"`, because this is the resample path.
- test_intervals_edge.py::test_local_resample_empty: `out.index.unit == empty.index.unit`, because an empty frame is a pass-through.
- test_intervals_edge.py::test_local_resample_same_granularity_unchanged: `out.index.unit == df.index.unit` (us), because same granularity is a pass-through.
- test_intervals_edge.py::test_local_resample_refuses_upsample_5m_to_3m: `out.index.unit == df.index.unit` (us), because the refused upsample returns the source.
- test_intervals_edge.py::test_local_resample_unknown_variant_returns_source: `out.index.unit == df.index.unit` (us), because an unsupported interval returns the source.
- test_tm11_edge.py::test_tushare_next_day_shift_matches_old: `out.index.unit == bars.unit` and `frame.index.unit == bars.unit` (us). Enrichment only adds columns and the price index passes through unchanged.
- test_tm2_17_broker_time_edge.py::`_assert_same` (used by every `_check` call): old and new are each asserted to equal `_parse_unit(times)`. `_bars_to_frame` (old and new) does not normalise, so it passes through the `pd.to_datetime` resolution: `us` on pandas 3, or `ns` when an input has more than 6 fractional digits (the ns, ns_zulu and nanosecond_precision cases).
