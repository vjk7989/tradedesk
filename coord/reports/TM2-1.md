- **backup.sh**
  - Default DEST is `/var/backups/tradedesk`, `KEEP` defaults to 14 and must be an integer ≥ 1 (otherwise exit 2), and `COMPOSE_PROJECT_NAME` defaults to `deploy`.
  - `TRADEDESK_DEPLOY_DIR` overrides the script's own dir when locating env/risk/compose files. The tests use it, and it's documented.
  - **Atomic build:** each backup is built in `DEST/.<stamp>.partial` and renamed to `DEST/<stamp>` only after MANIFEST and chmod succeed. An EXIT trap removes the partial dir on failure and is disarmed right after the rename, so a failed run never leaves a timestamped dir, and a retention failure can never delete the new backup.
  - Retention prunes only timestamp-pattern dirs, newest KEEP kept.
  - Inside the container, each tar is `chown`ed to the invoking uid:gid, so the host can chmod it 600.
  - `.env` is stored as `env`. Nothing prints file contents.
- **restore.sh**

  - Volumes are extracted over existing contents and **not** cleared first; the doc says so.
  - Existing env/risk files are moved to `*.pre-restore` and restored copies are chmod 600.
