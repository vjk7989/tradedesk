# O-17 report

## Root cause
`trade.place` / `trade.modify` called `gather()` before the risk engine. `gather()` does
`client.quotes()` (for the notional price), then `pnl()` (live) and `analyzerStatus()` (paper). All of
these are network calls. With a bad OpenAlgo apikey the quote failed with `HTTP 403`, so the
qty=500 order (maxQtyPerOrder=100) was never evaluated by the risk engine. It was audited as `error`,
not `denied`. The quantity check needs no market data but only ran after the network calls.

## Fix
- `RiskEngine.checkStatic(o, run)`: the same checks as `checkOrder` minus price/notional and day P&L.
  Reason texts and their order are unchanged (shared `evaluate()`).
- `trade.place` and `trade.modify` run `checkStatic` right after `parseOrder` and before `gather()`.
  A failure throws `risk denied: ...`, audited as `denied`, with zero client calls.
- The full `reserve()` / `checkOrder()` still runs after the quote, so reserve/commit/release and
  notional checks are unchanged.

## Notes
- The analyzer-ON requirement for paper mode is a network call, so it cannot run earlier. It runs
  after the static checks.
- When an order fails both a static check and a notional check, the denial text now lists only the static reasons.
- Pinned tests broken: none (2500 passed). New: `trade-mcp/test/o17_static_checks_first.test.ts`.
