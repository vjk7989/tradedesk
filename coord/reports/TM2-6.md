Decisions:
- **Schema:** optional `notify: { telegram: { chatIdEnv } }`, strict.
  - Only those keys are allowed, and `chatIdEnv` must match `^[A-Za-z_][A-Za-z0-9_]*$` (an env var NAME); anything else fails `parseJobs`.
  - A job without `notify` has no `notify` key, so existing tests are unchanged.
- **Hook:** `executeJob` calls `notifyTelegram` only after the report file is written, wrapped in try/catch, and then returns the path. Job status, file content and the return value never depend on notify.
  - `ExecDeps` gains an optional `fetch` (default `globalThis.fetch`) for injection. A job without notify makes no fetch.
- **Sending (`src/notify.ts`):**
  - The bot token comes from `TELEGRAM_BOT_TOKEN` and the chat id from the env named by `chatIdEnv`, both trimmed. If either is missing or blank, it logs one warning naming the variables (never values) and skips.
  - It POSTs `https://api.telegram.org/bot<TOKEN>/sendMessage` with JSON `{chat_id, text}` and `AbortSignal.timeout(10_000)`. A non-2xx response, a thrown error or a timeout gives one redacted `console.error`, and nothing is rethrown.
- **Text:** `<name>: ok|error`, `duration: N ms`, an optional `error:` line, then the result text, redacted first and then cut to 3500 chars. The limit applies to the result body; the short head is extra.
- **Redaction:** the MCP token and the bot token are redacted from the message and every log line, including caught error messages that could contain the URL.
- **jobs.example.json:** `pre-market-brief` has `"notify": {"telegram": {"chatIdEnv": "TELEGRAM_CHAT_ID"}}` (names only) and still parses.
- **README:** a "Telegram notifications" section plus a `notify` row in the schema table.
- **Tests (26):**
  - the exact URL, method, headers, body and `chat_id`;
  - 3500-char truncation;
  - neither token appears in the sent text or any log;
  - a thrown error, 4xx, 5xx and timeout leave the result and file unchanged (the timeout uses an already-aborted signal from a spied `AbortSignal.timeout` and asserts 10 000 ms);
  - no notify → no fetch; missing env → no fetch, with a secret-free warning;
  - parseJobs accept/reject cases; jobs.example.json parses.
