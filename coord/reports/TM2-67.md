# TM2-67 report: tz-aware price index in tushare fundamentals merge

## Change
`bt-service/vibe_bt/backtest/loaders/tushare_fundamentals.py` (only file edited): in `enrich_price_frames_with_fundamentals` the internal merge key `_trade_date` is built from the index; if the index is tz-aware it is `tz_convert("Asia/Shanghai")`, `tz_localize(None)`, then `.normalize().as_unit("ns")`. Naive indexes take the same path as before (normalize, as_unit ns). `merged.index = original_index` already restored the caller's index, so output index (tz, unit, values) is unchanged. `subdaily="next_day"` shifts the PIT date by one day against the CN-local date key, so UTC 2024-02-29 23:30Z (03-01 07:30 CST) sees the 03-01 rule.

## Reasoning
PIT dates are naive CN-local dates; tz-aware bar keys made merge_asof raise MergeError. Converting to CN-local wall-clock date is the correct comparable key.
