## uv vs pip
Chose `uv`. GitHub's Dependabot options reference lists `uv` as a supported package-ecosystem value (it appears in the `dependency-type` and ecosystem tables), and bt-service is managed by uv with a committed `uv.lock` (CI uses astral-sh/setup-uv), so `uv` updates the lockfile; `pip` would not.
