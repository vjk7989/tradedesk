# TM2-27 report: risk.status reports every configured limit

## Change
`RiskEngine.status()` in trade-mcp/src/risk/engine.ts (check logic untouched):
- `limits` has every riskSchema key. Unset `maxShortOptionQtyPerOrder` is `null`.
- `limits.contractValues` is a count; `limits.marketHolidays` is `{NSE: n, MCX: n, nextNSE: "YYYY-MM-DD"|null}` (earliest NSE holiday on/after today's IST date).
- `today` adds `remainingOrders = max(0, maxOrdersPerDay - orders)` and `remainingNotional = max(0, maxNotionalPerDay - notional)`, using the same counters as checkOrder (CRYPTO adds no INR notional). The only optional limit is maxShortOptionQtyPerOrder, which has no "remaining" value, so no remaining field is ever null. Documented in the method comment.
- Built field by field from the config, so no env values or secrets can leak.
