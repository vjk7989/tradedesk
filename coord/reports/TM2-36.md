# TM2-36 report: agent-runner --history [N]

Files: agent-runner/src/history.ts (new), src/main.ts (arg handling), test/tm2_36_history.test.ts (new, 7 tests), README.md (one line).

- `--history [N]` / `--history=N` (default 20, 1..200; errors worded like --next). Any other `--history*` form (e.g. `--history5`) is an error, so none reaches the scheduler.
- Combining with --once, --check, --next, --dry-run (bare or `=` form) is an error.
- Reads `<outputDir>/<job>/<date>[-n].md` for jobs in jobs.json; parses only the header (title time, status, duration). Bodies and error text are never printed.
- Sorted newest first by header timestamp, then -n numerically.
- Status: the runner writes `ok` or `error`; `error` with `- error: refused` prints `refused`, other errors print `failed`.
- Empty, malformed, unreadable or unknown-status reports are skipped and counted (`skipped N unreadable`).
- Tests spy on spawn/execFile and fetch and assert runTask/runScheduler are never called.
- Verification: vitest 30 files / 955 tests passed (7 new), tsc clean, build OK. Existing tests untouched.

`--history=2` printed the top 2 + skipped line; `--history 5 --check` -> "--history cannot be combined with --check" (exit 1); `--history 300` -> "--history N must be between 1 and 200" (exit 1).

## Fix round 1
- history.ts: header parsing is first-match-wins and stops at the first `- error:` line, so error text cannot spoof status or duration.
- history.ts: reads at most the first 4096 bytes per report (open/read/close); a header that does not end within 4 KiB is skipped and counted.
- history.ts: only regular files are read (lstat); symlinks, FIFOs and devices are skipped and counted as unreadable.
- main.ts: job name and path columns go through the same redactor() as --dry-run, with the short-secret rule (prints the withheld text).
- Result: vitest 31 files, 1025 tests, 1024 pass; tsc and build clean. The 3 red bug tests now pass. Remaining failure: edge test "DOCUMENTED: a report symlink ... IS followed", which fails by design (symlinks are now skipped); the test writer must update it.
