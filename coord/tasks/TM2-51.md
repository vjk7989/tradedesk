# TM2-51 · bt-service · walk-forward: guard against a non-list `equity`
Branch: tm2/TM2-51        Base: main        Owner: TM2

## Finding
A test run whose `equity` is truthy but not a list raises AttributeError in the OOS-equity loop (`bt_service/walkforward.py` ~L208). `run_backtest` always returns a list today, but walk-forward must not crash on a malformed engine result.

## Files you may touch
- `bt-service/bt_service/walkforward.py`: the guard only.
- `bt-service/tests/test_tm2_51_wf_equity_guard.py` (new)

## What to build
If `equity` isn't a list of point dicts, skip it for the OOS curve and add a warning `fold <i>: unexpected equity shape (<type>)`. Don't crash. The rest of the fold result stays as it is.

## Acceptance criteria
- Cases: None, a dict, a string, a number, a list with non-dict items, and an empty list.
- No exception in any case, the right warning, and other folds unaffected.
- The full bt suite stays green.

`cd bt-service && uv sync && uv run pytest -q`
