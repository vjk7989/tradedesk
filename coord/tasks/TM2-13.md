# TM2-13 · bt-service · make the Windows-only backslash path test Windows-only
Branch: tm2/TM2-13        Base: main (latest)        Owner: TM2 (test-writer task)

`tests/test_extraction.py::test_safe_run_dir_windows_backslash_path` fails on Linux, both on main and in CI-like runs. It builds `\tmp\...` from a POSIX tmp path. On POSIX a backslash is a normal filename character, so `safe_run_dir` correctly treats the result as a relative name. The behaviour it checks only exists on Windows.

## Files you may touch
- `bt-service/tests/test_extraction.py`: that one test only. This is a test-writer task.

## Build
- Add `@pytest.mark.skipif(sys.platform != "win32", reason="backslash is a path separator only on Windows")` to that test. Its assertion is unchanged.
- Add a POSIX counterpart next to it, skipped on Windows: on POSIX, a backslash path is not treated as a separator. `safe_run_dir("a\\b")` resolves to `<cwd>/a\b`, a single component; use `monkeypatch.chdir(tmp_path)`.
- No source change.

## Acceptance criteria
- The full bt-service suite has no failures on Linux.
- On Windows, the original test still runs.
- No other test is edited.
