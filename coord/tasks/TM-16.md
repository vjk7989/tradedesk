## What to build
1. **Salted IP hash:** key persisted rate-limit entries with `HMAC-SHA256(secret, ip)`, not a plain hash.
   - Derive the secret from existing material, e.g. `OAUTH_PASSWORD_HASH` plus a fixed label via HMAC/HKDF. Add no new env var.
   - Old entries that don't match are simply ignored, so rate limits reset once.
2. **No persist on unknown codes:** a token request with an unknown or expired code writes nothing to the store.

## Acceptance criteria
- A raw IP never appears in the persisted file. The test greps for IPv4 and IPv6 test addresses.
- Different secrets give different keys, and the same secret gives a stable key across restarts.
- 1000 bad-code requests cause zero store writes (spy on the writer).
- All existing tests, including the TM-13 edge tests, stay green, and no existing test is edited.
