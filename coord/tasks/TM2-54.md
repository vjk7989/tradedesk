- "busy: too many concurrent executes, retry shortly": already listed; link to it.
- "sandbox init failed": the operator should file an issue.

Quote every error string verbatim from `trade-mcp/src/sandbox/quickjs.ts` and `src/server.ts`, and give file:line in the report. Link ADR-18/19.
