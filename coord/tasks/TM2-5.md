## What to build
`GET /readyz`, no auth, returns `{ok, checks: {openalgo, bt, auditWritable}}`. Each check is `"ok"`, `"fail"`, or (bt only) `"not_configured"`.
- **openalgo:** a cheap call with a 3 s timeout. Use an existing client method such as `analyzerStatus()`.
- **bt:** `GET {btUrl}/healthz` with a 3 s timeout.
- **auditWritable:** the same writability probe the order path uses.

Rules:
- Return HTTP 200 if every configured check is ok, otherwise 503.
- Never include URLs, keys, tokens, error text or stack traces in the response.
- Cache the result for 5 s.

## Acceptance criteria
- Every ok/fail combination returns the right status code.
- A timeout counts as fail within 3 s; test it with a fake fetch that never resolves.
- No secrets in the response body.
- `/healthz` is unchanged.
- The cache prevents a second upstream call within 5 s.
- Existing tests stay green.
