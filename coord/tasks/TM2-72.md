# TM2-72 · paper-bot · dashboard: per-symbol P&L + CSV export
Branch: tm2/TM2-72        Base: main        Owner: TM2

## Why
The owner watches the live paper-bot dashboard on GCP and wants to see every trade and decision clearly. Add a per-symbol breakdown and downloadable history.

## Files you may touch
- `paper-bot/` web and stats modules only: the dashboard/route file and the stats module, at most 3 files.
- `paper-bot/tests/test_tm2_72_dashboard.py` (new)

## What to build
- **Per-symbol card row:** for each symbol, show realised P&L, unrealised P&L, trades, win rate, current side, and the last decision with its reason.
- **CSV export:**
  - `/api/trades.csv` and `/api/decisions.csv`, with all rows, newest first, and proper CSV escaping;
  - optional `?symbol=` and `?action=` filters, using the same whitelist as the HTML filter;
  - links on the dashboard.
- **Safety:**
  - no secrets or env values;
  - Content-Disposition attachment;
  - **CSV-injection safe:** prefix cells starting with `= + - @` with `'`.

## Acceptance criteria
- Correct numbers on fixture DBs: empty, one symbol, two symbols, a reversal.
- CSV round-trips with Python's csv reader.
- Injection payloads are neutralised.
- Existing paper-bot tests stay green and unedited.

`cd paper-bot && uvx --from uv==0.9.26 uv sync && uv run pytest -q`
