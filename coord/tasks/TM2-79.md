## What to build
A shared `(security_headers)` snippet imported by all three sites:
- `Strict-Transport-Security: max-age=31536000` (no preload: the sslip.io deploys rotate);
- `X-Content-Type-Options: nosniff`;
- `Referrer-Policy: no-referrer`;
- `X-Frame-Options: DENY` on dash and mcp;
- remove `Server`.

For the dash site only, also set a strict `Content-Security-Policy`: `default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self'; frame-ancestors 'none'`. Check the paper-bot dashboard really works under it (it uses inline CSS and SVG; check whether it has any inline JS such as the auto-refresh, and adjust either the CSP or a meta refresh).

Don't break OpenAlgo's UI. Apply a looser policy to openalgo, or none, and say which in the report.
