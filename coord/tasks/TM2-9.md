## What to build
`node dist/risk/lint.js <path-to-risk.json> [--today YYYY-MM-DD] [--strict]`:
- Parse the file with `riskSchema`, the same schema the server uses. Never write a second schema.
- On a parse error, print each zod issue as `path: message` and exit 1.
- On success, print a short summary: per-order caps, daily caps, the allowlist size, the contractValues count, and the holiday count per year.
- Then print warnings. They exit 0, or 2 with `--strict`. Warn when:
  - there are no holidays for the current year (or the `--today` year);
  - a holiday date is not a real date (2026-02-30) or is duplicated;
  - a holiday falls on a Saturday or Sunday;
  - a crypto symbol in the allowlist has no `contractValues` entry. Do this only if the schema has both; otherwise skip it.
- Read-only: it never prints env values and makes no network calls.
