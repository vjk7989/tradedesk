## What to build
- `STRATEGY=sma_cross|rsi_revert`, default `sma_cross`, which keeps today's behaviour byte-identical.
- `rsi_revert`:
  - RSI(`RSI_LEN`=14) on closed candles only;
  - go long when RSI < `RSI_LOW` (30), exit or flat when RSI > 50;
  - go short when RSI > `RSI_HIGH` (70), if ALLOW_SHORT;
  - write the reason text with the RSI value.
- Startup validation:
  - 2 ≤ RSI_LEN ≤ 100;
  - 0 < LOW < 50 < HIGH < 100.
- Use the same fill, fee and restart machinery as sma_cross; don't duplicate it.

## Acceptance criteria
- RSI matches a reference calculation (Wilder smoothing) on fixtures.
- No look-ahead.
- Correct entries and exits.
- Validation errors are clear.
- The sma_cross tests are unchanged and green.
